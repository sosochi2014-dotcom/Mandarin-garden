# Лендинг Mandarin Garden Сочи

Сайт для домена **мандарингарденсочи.com** (в техническом виде `xn--80aaalddhue5amdeoweu3i.com`).

## Контакты
В конце `index.html` блок `CONTACTS`: телефон, WhatsApp, `telegram` (логин без @) и `max` (ссылка на профиль). Пока Telegram пустой, кнопка Telegram скрыта.

## Карта
В конце `index.html` блок `MAP`. Сейчас метка ставится по адресу. Для точной метки впишите координаты в `ll` в формате `"долгота,широта"` (например `"39.95,43.40"`). В Яндекс Картах их видно, если нажать на точку правой кнопкой → «Что здесь?» (там порядок широта, долгота, поменяйте местами).

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите в него **всё содержимое** этой папки (index.html, CNAME, .nojekyll, папки img и video).
2. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. В Custom domain должно стоять `xn--80aaalddhue5amdeoweu3i.com` (подтянется из файла CNAME). Когда сертификат будет готов, включите *Enforce HTTPS*.
